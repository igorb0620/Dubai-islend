# Presentations

Папка для веб-презентаций по недвижимости ОАЭ.

Каждый проект хранится в отдельной папке внутри `presentations/`, например:

- `presentations/sobha-city/`
- `presentations/yas-residences/`
- `presentations/marsa-al-saadiyat/`

Внутри каждой папки проекта основной файл презентации — `index.html`, дополнительные материалы можно хранить в `images/` и `assets/`.
